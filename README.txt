GisaWebs website starter

FILES
- index.html: complete responsive website (HTML + CSS + small JavaScript)

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html to open it in your browser.

BEFORE SHARING
1. Open index.html in VS Code or Notepad.
2. Find YOUR_EMAIL@example.com.
3. Replace every occurrence with an email address you can safely use for enquiries.
4. Save the file and refresh your browser.

IMPORTANT
- The prices are editable examples, not guaranteed market rates.
- This is a static website; the contact button opens the visitor's email app.
- Because the owner is under 18, ask a parent/trusted adult to help with customer agreements, payment arrangements, and publishing.
- Do not put a home address, school details, or private personal information on the site.
